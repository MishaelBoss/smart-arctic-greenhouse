# ❄ Smart Arctic Greenhouse («Умная теплица для Арктики»)

Проект разработан для участия во всероссийском фестивале **«Школа Росатома»** по направлению **«Арктика — 2035: моделируем будущее»**.

Система представляет собой аппаратно-программный комплекс автоматизированного выращивания растений в суровых арктических условиях с возможностью локального автономного управления, облачного мониторинга через REST API и кроссплатформенного десктопного приложения.

## 🚀 Основные функции

1. **Климат-контроль:** При температуре выше 28°C автоматически открывается крыша (сервопривод MG995), при падении ниже 22°C — закрывается (с гистерезисом).
2. **Автополив:** При снижении влажности почвы ниже 30% включается погружной насос через модуль реле, при достижении более 60% — выключается.
3. **Имитация полярной ночи:** При падении уровня освещенности ниже порога фоторезистора активируется фитодосветка (светодиоды).
4. **Локальная индикация:** OLED-дисплей SSD1306 (128x64, I2C, адрес `0x3C`) в реальном времени отображает влажность почвы, температуру и статус исполнительных элементов.
5. **Двусторонняя связь:** Поддержка работы как по **Wi-Fi** (через FastAPI + PostgreSQL бэкенд), так и локально по **USB (Serial)**.
6. **Десктопное приложение (Avalonia UI):** Кроссплатформенный интерфейс с темной арктической темой, интерактивными графиками (LiveCharts2) и панелью ручного управления.

## 🛠 Технологический стек

- **IoT Firmware:** C++ (Arduino IDE), ESP32, Adafruit SSD1306, DHT, ESP32Servo, ArduinoJson.
- **Backend:** Python 3.14.6, FastAPI, SQLModel, PostgreSQL (`psycopg[binary]`), Pydantic, Uvicorn.
- **Desktop App:** C# .NET 10.0, Avalonia UI 12.1.2, CommunityToolkit.Mvvm, LiveChartsCore.SkiaSharpView.Avalonia, Serilog.

## ⚙️ Инструкция по запуску

### 1. PostgreSQL & Backend
```bash
cd backend
pip install -r requirements.txt
# Создайте БД greenhouse в PostgreSQL и настройте .env
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 2. Avalonia Desktop App
```bash
cd GreenhouseApp/GreenhouseApp.Desktop
dotnet run
```

### 3. ESP32 Firmware
Откройте `arduino/sketch_sep10a/sketch_sep10a.ino` в Arduino IDE, укажите данные вашего Wi-Fi (`WIFI_SSID`, `WIFI_PASS`), адрес бэкенда (`API_BASE`) и загрузите прошивку на плату ESP32.
